## 2026-09-28 - Layout Shift Prevention & useId()
**Learning:** When adding focus, active state borders, or toggling borders with Tailwind (like on Buy/Sell buttons), adding a `border border-transparent` class to inactive states prevents 1px layout shifts when clicking. Additionally, dynamically assigning `id` attributes via React's `useId()` hook ensures form label associations don't clash, avoiding duplicate ID bugs while maintaining strict accessibility for screen readers via `sr-only` classes on unlabeled input contexts.
**Action:** Apply `border border-transparent` to visually 'borderless' interactive components to reserve space, and uniformly implement `useId()` in reused inputs mapped to semantic label elements, defaulting to `sr-only` when visual labels disrupt design.
